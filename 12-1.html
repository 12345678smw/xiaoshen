集中定义

在 :root 中统一定义颜色、间距、圆角等变量，全站通过 var() 引用，修改一处即可全局生效。

var(--smw_primary)

动态修改

通过 JavaScript 的 setProperty 修改变量值，无需重新编译，页面样式实时更新，这是 CSS 变量相比 Sass 变量的优势。

setProperty()

作用域覆盖

CSS 变量遵循层叠继承规则，可在局部容器中覆盖变量值，只影响该容器内部，实现局部主题。

局部覆盖
