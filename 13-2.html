Lucide 图标（SVG 形式）

沈明伟

SVG 图标原理： Lucide 是纯 SVG 图标库，每个图标是一段矢量路径。页面中先写占位标签 <i data-lucide="house"></i>， JS 调用 lucide.createIcons() 后会把占位元素替换为真正的 <svg> 标签（内联在 HTML 中）。 因为是 SVG，可以直接用 CSS 的 stroke、fill、width/height 控制， 矢量缩放不失真。本页面使用的 lucide.min.js 已下载到本地 cdn/ 目录，可离线使用。
