Font Awesome 字体图标

沈明伟

字体图标（Font Icon）原理： 图标以「字体文件」的形式存在，通过 CSS 的 @font-face 引入 woff2 字体， 用 ::before 伪元素把字符（如 \f015）渲染成图标。 使用时只需给元素加上类名：<i class="fa-solid fa-house"></i>， 像设置文字一样用 font-size 和 color 控制图标的大小与颜色。 本页面使用的 CSS 与字体文件均已下载到本地 cdn/ 目录，可离线使用。
