JavaScript 两种定时器

一次性 setTimeout 与周期性 setInterval · 原生 JavaScript 交互演示

① 一次性定时器

setTimeout

延迟指定时间后只执行一次回调，执行完自动结束；可在到点前用 clearTimeout 取消。

const smw_id = setTimeout(() => {
  console.log('时间到');
}, 3000);

clearTimeout(smw_id); // 取消

    ② 周期性定时器

    setInterval

    按固定间隔反复执行回调，直到用 clearInterval 清除；适合倒计时、轮询、时钟。

    const smw_id = setInterval(() => {
  console.log('每 1 秒执行一次');
}, 1000);

clearInterval(smw_id); // 停止
