字体图标（Font Icon）方案

底部导航使用 iconfont 字体图标方案：图标以字体文件（woff2/woff/ttf）形式存在， 通过 CSS 的 @font-face 引入，用 ::before 伪元素把 Unicode 字符渲染成图标。 导航项使用「首页 / 社区 / 搜索 / 我的」四个图标， 其中社区、我的带数字徽章，搜索带右上角红点。

图标像文字一样，用 font-size 控制大小、color 控制颜色，矢量缩放不失真。
全屏宽度固定底部，flex 平分四项，适配移动端各种屏幕宽度。
已适配 iOS 安全区（env(safe-area-inset-bottom)），避免被 Home 指示条遮挡。
